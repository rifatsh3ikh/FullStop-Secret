# FullStop-Secret

FullStop Secret is a desktop application for generating strong, secure, and customizable passwords. Built with Python and the `customtkinter` library, it provides a simple and clean user interface for creating passwords tailored to your security needs.

## Features

- **Customizable Length**: Generate passwords from 8 to 32 characters long using an intuitive slider.
- **Character Set Control**: Choose to include or exclude lowercase letters, uppercase letters, numbers, and symbols.
- **Secure Generation**: Uses Python's `secrets` module to ensure cryptographically strong random password generation.
- **Modern UI**: A sleek, dark-mode interface built with `customtkinter`.
- **Real-time Feedback**: The length label updates instantly as you adjust the slider.

## Prerequisites

- Python 3
- `customtkinter` library

## Installation

1.  Clone the repository to your local machine:
    ```sh
    git clone https://github.com/rifatsh3ikh/FullStop-Secret.git
    cd FullStop-Secret
    ```

2.  Install the required Python library:
    ```sh
    pip install customtkinter
    ```

## Usage

Run the `main.py` script to launch the password generator:

```sh
python main.py
```

Once the application is open:

1.  Adjust the **Length** slider to set your desired password length.
2.  Use the switches to toggle the inclusion of **Lowercase**, **Uppercase**, **Numbers**, and **Symbols**.
3.  Click the **GENERATE** button.
4.  Your new password will appear in the display box at the top. You can then manually copy it.
